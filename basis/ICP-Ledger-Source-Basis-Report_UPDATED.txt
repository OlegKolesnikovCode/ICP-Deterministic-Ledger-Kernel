2.1 Ownership Rule

OWN-001:
Each correctness-sensitive concept MUST have exactly one owning SRC file.

OWN-002:
A non-owner SRC file MAY reference an owned concept but MUST NOT redefine it.

OWN-003:
If two SRC files define the same correctness behavior differently, generation MUST stop with SOURCE_CONFLICT.

OWN-004:
If no SRC file owns a correctness-sensitive behavior, generation MUST stop with SOURCE_GAP or ROUTING_GAP.
